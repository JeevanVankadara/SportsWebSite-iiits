# IIITS Sports viewer design

Scope: `src/viewer`, independent of admin and coordinator UI.

White, charcoal and neutral gray. 4px spacing increments. Rounded 20–24px cards, floating pill navigation, SF Pro system typography with Inter fallback. Both light and dark appearances, visible top navigation toggle, saved locally.

Reference: [Tubelight Navbar by Ayushmaan Singh (MIT)](https://21st.dev/@ayushmxxn/components/tubelight-navbar). The floating pill and compact active item pattern is adapted locally without colored glow. Source import requires an API key; none was supplied. 21st CLI review completed on changed viewer files. Its hardcoded-color notices describe token definitions, and autofocus is intentional only inside a user-opened accessible search dialog.

Generated fictional athlete portraits are decorative, not student likenesses. One-time Remotion profile entrance and neutral Lottie live indicator respect reduced motion.
